01. X Gate — The Bit Flip

The X Gate changes |0⟩ into |1⟩ and |1⟩ into |0⟩.

X

|0⟩ → X Gate → |1⟩

Think of it like an ON/OFF switch. The X Gate flips the qubit's state.

Expected result: 100% measurement of 1 when starting from |0⟩.

02. H Gate — Superposition

The Hadamard Gate transforms |0⟩ into an equal superposition of |0⟩ and |1⟩.

H

|0⟩ → H Gate → Superposition

When measured, the outcomes are approximately 50% zero and 50% one.

03. Z Gate — The Phase Flip

The Z Gate changes the phase of the |1⟩ component of a quantum state.

Z

|0⟩ → Z Gate → |0⟩

If the qubit is in |0⟩, applying Z does not change its state.

If the qubit is in |1⟩, Z changes its phase without changing its measurement value.

A phase change becomes observable when we combine gates such as H, Z and H.

04. CNOT Gate — Controlled Operation

CNOT is a two-qubit gate. It flips the target qubit only when the control qubit is 1.

CX

Control Qubit → Target Qubit

Control = 0: target remains unchanged.

Control = 1: target flips.

This gate is essential for creating entanglement in our Bell State experiment.

05. Combine Gates into a Circuit

A quantum circuit is built by applying gates in a particular sequence.

H → X → H → Measurement

First, create superposition using H. Then apply X and another H gate. Finally, measure the qubit.

This sequence demonstrates how gates combine to transform a quantum state.
